# Патч `tailwind.config.js` — токены под Component specs

> Что делает: **добавляет** недостающие смысловые токены в `dark-*`, вводит
> второй золотой (`gold-dark`) для тёмной темы, чинит muted-контраст на уровне
> токена. Твою `corn-*` палитру НЕ трогает. Ничего не удаляет.
>
> Как применять: замени блок `colors: { … }` в своём `tailwind.config.js`
> на версию ниже. Остальные части конфига (fontFamily, fontSize, animation,
> keyframes, backgroundImage) оставь свои — я их не меняю.

```js
colors: {
  // ─────────────────────────────────────────────────────────
  // Pre-auth cornsilk palette — БЕЗ ИЗМЕНЕНИЙ (welcome тема)
  // ─────────────────────────────────────────────────────────
  corn: {
    50:  '#FFFDF0',
    100: '#FFF8DC',  // pure cornsilk — фон welcome
    200: '#FAF4CC',
    300: '#F5EFB8',
    400: '#EDE39A',
    500: '#D4C66A',
    600: '#B5A23A',
    700: '#8B6914',  // amber accent — ЗОЛОТО ДЛЯ WELCOME (на cornsilk)
    800: '#5C4A1E',  // warm brown — вторичный текст welcome
    900: '#1A1208',  // primary text welcome
  },

  // ─────────────────────────────────────────────────────────
  // Post-auth dark palette — ДОСТРОЕНА до полного набора токенов
  // (раньше были только фоны 50–900; текст/muted/surface/border
  //  жили хардкодом по компонентам → отсюда разъезжались экраны)
  // ─────────────────────────────────────────────────────────
  dark: {
    // фоны (твои существующие — оставлены)
    50:  '#1C1C24',
    100: '#16161E',
    200: '#111118',
    300: '#0D0D14',
    900: '#08080F',   // база под radial gradient

    // НОВЫЕ смысловые токены тёмной темы:
    surface:  '#16150F',  // карточка/панель на тёмном
    surface2: '#1E1C14',  // вложенная поверхность (комментарий внутри карточки)
    text:     '#F5F0DF',  // основной текст И заголовки на тёмном
    muted:    '#B8AE93',  // вторичный текст — ОСОЗНАННО светлый.
                          // НЕ опускай яркость ниже: прошлая проблема — muted тонул на тёмном.
  },

  // ─────────────────────────────────────────────────────────
  // ЗОЛОТО ДЛЯ DASHBOARD — новый токен.
  // corn-700 (#8B6914) тускнеет на тёмном фоне; на дашборде нужен
  // более светлый оттенок — это то золото, что де-факто на скринах
  // кнопок Register/Connect.
  // ─────────────────────────────────────────────────────────
  gold: {
    dark: '#C79A3A',       // accent для тёмной темы (кнопки, активная вкладка, дедлайн-бейджи)
  },
},
```

Плюс добавь (или подтверди наличие) hairline-бордера тёмной темы. Проще всего
классом-утилитой прямо в specs: `border-white/10` = `rgba(255,255,255,0.10)`
для тёмного hairline. Отдельный токен заводить не обязательно.

## Сверка после вставки (обязательно)

Значения `dark.*` и `gold.dark` сняты с твоих скриншотов и приведены к
читаемому контрасту — они близкие, но не пипеткой из рантайма. После вставки:

1. Открой любой тёмный экран, пипеткой сними реальный фон карточки → сверь
   с `dark.surface #16150F`, поправь если надо.
2. Пипеткой сними реальное золото кнопки Register → сверь с `gold.dark #C79A3A`.
   Если на экране оно другое (возможно, там сейчас захардкожен иной hex) —
   впиши реальное значение в `gold.dark`, и дальше все кнопки возьмут его.
3. Правишь ТОЛЬКО здесь, в конфиге. Значение разойдётся по всем экранам.
